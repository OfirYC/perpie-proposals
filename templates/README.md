# Canvas → asset pipeline (support scripts)

These are helpers for turning the Pencil canvas into branded PNGs. The proposal
itself is generated by the repo's own system — see `src/` and `scripts/`:

    npm run build                  # render assets
    npm run notion:create -- vertex   # clone the proposal + splice the AI pivot

| File | Purpose |
|---|---|
| `render.py` | Canvas board -> branded PNG at exact size (headless Chrome) |
| `brands.json` | Protocol palettes + logos mirrored from `protocols/catalog.json` |
| `build.py` / `split.py` / `check.py` | Pencil HTML export -> tokenised whitelabel preview |

Usage:

    python3 render.py --brand Vertex --scale 2 --out ../dist/vertex/images

A previous Python-based proposal/Notion generator lived here; it duplicated
`scripts/notion.mjs` and has been moved to `.superseded/py-generator/`.
